### Storyline
Want a proper storyline with quests. Imagine a game like final fantasy, we would like to experience something like 
that in minecraft. So leveling, unlocking new areas, new weapons, friends and enemies. Special fights, a lot of things. 
Dont make it turn based though. Basic minecraft fighting with weapons or tools.

## Progression
- The whole game is progression based, backed by a proper storyline. 
- The idea is to make the game harder and harder over time. 
- In the very beginning only few items can be crafted and or gathered. The user has to unlock them. 
There are systems in palworld OR more general unlock features in other games. We have to find one. 
- Progression should never really end, and should not be too fast.
- So in the beginning we just only have like bow or swords, but may later progress to new planets
with ressources for gathering elements for weapons etc.
